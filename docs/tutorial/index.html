PrintArtZ — Project Training Guide

A hands-on "learn a real full-stack project" course. Understand how PrintArtZ is built, then study each technology in an interview Q&A format — from basics to advanced — so you could walk into a full-stack interview and explain it all.

Big picture: a website has two halves — the frontend (what you see in the browser) and the backend (code on a server that talks to databases and other services). PrintArtZ keeps both in one codebase (Next.js) and calls out to specialist services (a database, an AI image generator, a payment company…).

How to use this guide

Start with How PrintArtZ works to see the moving parts, then open a Study topic. Each topic is a set of interview-style questions with answers and real code — click a question to expand it.

🎯 Goal: after finishing the topics you should be comfortable with TypeScript, React, Next.js, PostgreSQL, ORMs, CI/CD, servers/hosting and AI app concepts — the exact stack this project uses.
