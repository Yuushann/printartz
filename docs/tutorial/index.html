PrintArtZ — Project Training Guide

Welcome! Think of this as a mini 3-month "real project" course. PrintArtZ is a website where parents describe a school art project and get a printable image. This guide explains every technology we use, in plain English — assuming you know nothing yet. Each card has a keyword to Google when you want to go deeper.

🧱 Tech stack 🧩 Services + status 🔐 Login flow 🔄 Data flow
Big picture: A website has two halves — the frontend (what you see in the browser) and the backend (code on a server that talks to databases and other companies' services). PrintArtZ's frontend and backend live in one codebase (Next.js), and it calls out to specialist services (a database, an AI image generator, a payment company, etc.).
